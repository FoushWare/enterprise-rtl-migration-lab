## Reproduce to a new version
Use installed Python with Pillow for source/render-scene02.py and qa-scene02.py; use the bundled Python3.12 for the documentation scripts as well (system Python3.9 rejected some long Unicode source lines). FFmpeg7.1.1 with libx264/libass, system Arial, and existing raw sources are required. Browser audit uses installed Chrome156 and local @playwright/test. No dependency installation performed.

Order: prepare.py → audit.mjs/interactions.mjs (runtime evidence) → render-scene02.py → voiceover.py → sound-design.py → export-scene02.py → qa-scene02.py → assemble-master.py → verify-final.py. Existing sources are never regenerated by this pipeline. Use a new production root for revisions; outputs refuse overwrite or skip existing paths. Initial attempts are retained in clearly named intermediate folders and not deliverables.

Only rerun audit scripts against an authorized Study server. They use a disposable browser context; settings save stays in that context, not the user’s profile. No new invoice is created. Do not rerun preparation to replace the original before-state snapshot; preserve the audit receipt.
