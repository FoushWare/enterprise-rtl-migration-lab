# Scene 01 — Cinematic opening, first 10 seconds

**Draft — Pending Review.** Only the 00:00–00:10 opening is produced. Scene 02 and historical assets are untouched. This is a fictional educational expansion story, not a real customer network.

## Rendering approach

Actual Three.js 0.170.0 WebGL geometry rendered frame-by-frame in headless Chrome, then encoded with FFmpeg/libx264. Blender was not installed; Three.js is the chosen genuine 3D alternative. Earth is a sphere with separate day/night textures and custom lighting shader. Atmosphere is a Fresnel shader shell. Pins and elevated great-circle routes are 3D geometry anchored to geographic coordinates; the camera changes its position around the sphere. The title is animated HTML composited over the WebGL render. No storyboard image or dashboard screenshot is used as footage.

## Timeline

- 0–3 seconds: Europe-centered orbital establishing view; headquarters pin emerges.
- 3–7 seconds: eased camera travel toward the Middle East, three drawn arcs and sequential destination pins.
- 7–10 seconds: camera settles, title fades in, final network composition holds for the next edit. No baked fade to black.

Fictional HQ uses Frankfurt-area coordinates (50.11,8.68). Destination anchors: Cairo (30.0444,31.2357), Riyadh (24.7136,46.6753), Dubai (25.2048,55.2708). These are illustrative city-center anchors, not office addresses. The geographic texture is a visualization asset, not a political boundary authority. No country labels are used.

## Editable project

- `source/scene.js`: camera, geography, materials, procedural stars, 3D pin/route animation, deterministic frame seeking.
- `source/index.html`: title composition and typography.
- `source/render.mjs`: offline frame capture and H.264 encoding.
- `source/vendor/three.module.js`: pinned renderer.
- `source/textures/`: downloaded Earth textures.
- `outputs/`: draft MP4, five representative frames and verification receipt.

Dependencies used from the existing environment: Node22.21.1, @playwright/test1.64.0, installed Google Chrome and FFmpeg7.1.1. No application package manifest or dependency installation was changed. Local rendering uses SwiftShader software WebGL; this affects render speed, not exported frame timing.

From the repository root:

```sh
node assets/scene-01-opening-v1/source/render.mjs --preview
node assets/scene-01-opening-v1/source/render.mjs
```

Full export refuses to overwrite an existing MP4. Choose a new version folder/output name for revisions. To inspect/edit the live scene, serve `source/` with a local HTTP server and open its index; without `?render`, the ten-second scene loops. No external CDN is needed during rendering after the bundled assets have been downloaded.
