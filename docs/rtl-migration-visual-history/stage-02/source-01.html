0002
0003  **Audit date:** 11 October 2026. **Scope:** existing English LTR source, both applications, shared UI/data libraries, installed MUI behavior, tests and screenshot assets. **Disposition:** ready for a controlled Phase 2 proposal; not ready to declare RTL support. No application, configuration, dependency, test or baseline changes were made. Only this report was added. 0005  ## 1. Readiness assessment
0006
0007  The strongest migration seam is the shared Provider and AppShell: both applications already consume them. The main blockers are an immutable LTR theme, LTR document roots, no application-owned RTL Emotion cache, and shell geometry tied to the left side. Layout is split across plain CSS, Emotion templates, MUI `sx`, and React inline styles. One styling strategy cannot automatically handle all four.
0008
0009  There are genuine automation candidates in decorative spacing and start/end affordances. Shell placement, SVG charts, directional meaning, mixed text and field behavior require decisions before transformation. Existing LTR tests provide a useful safety net, but they do not establish RTL correctness. All future implementation recommendations below require approval first.
0010
0011  **Evidence boundary:** source findings are confirmed in the current files. RTL symptoms are predictions from that source and installed library behavior, not observed RTL failures. The current English application is intentionally LTR; these are migration challenges, not accusations of broken LTR behavior.

0032  ## 3. Classification rules
0033
0034  - **Safe automation candidates (A):** bounded syntax changes with clear reading-start/reading-end intent. This is a candidate list, not authorization to apply transformations. Preserve LTR screenshots and review output after eventual changes.
0035  - **Requires manual review (M):** product semantics, coupled geometry, chart coordinates, glyphs, content direction or reading/interaction order. A textual match is insufficient to choose the final behavior.
0036  - **Requires runtime RTL configuration (R):** document direction, MUI direction context, Emotion processing, portal inheritance and locale-dependent rendering. Static property replacement cannot supply these.
0037
0038  Classifications describe the primary treatment. Some manual findings also depend on runtime configuration. Symmetric padding, gaps, centered content and vertical spacing are not automatically RTL defects.
