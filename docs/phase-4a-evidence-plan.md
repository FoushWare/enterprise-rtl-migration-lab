## Collection protocol and decisions

Capture textContent, exact copied/selected text, neighboring Arabic/Latin punctuation and per-character Range rectangles; full-width container overlap alone is insufficient. Compare regular and known problematic seed names such as Evergreen & Co.; test mixed user inputs only in transient UI or a separately approved fixture, not mutated seed data. Check mobile overflow/line wraps and different script-leading names. Do not force an intended RTL name into LTR merely to make an assertion pass.

If new captures are approved, write them only under a new docs/screenshots/phase-4a-evidence/ directory with commit/browser/locale/fonts/viewport/state/steps metadata; never overwrite phase-2a or six English baselines. No such directory exists from this stage. Store per-ID conclusion and scope; record no-reproduction separately from valid-risk acceptance. Native date/caret/IBAN examples outside this 18-ID set are policy coverage extensions, not fabricated scanner matches. Locale decisions require reviewer evidence; a screenshot cannot grant formatting approval.
