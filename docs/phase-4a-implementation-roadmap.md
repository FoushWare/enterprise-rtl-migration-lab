## Proposed small component slices

1. Shell: choose right reading-start RTL with matched gutter/border/active stripe, mobile sign and print reset; preserve English left geometry.
2. Runtime-generated controls then alignment/clearance: verify MUI alone resolves symptoms before custom patch; define numeric/human/token columns and input direction; Modal clearance is separately accepted.
3. Chart: fixed LTR chronological frame and Arabic labels, exact source data unchanged; no coordinate mirroring.
4. Bidi/brand/icons: explicit token grouping, complete Latin brand island, direction-aware custom progression only; no locale display change without separate approval.

These are proposed orderings inside 4E, not authority to implement several at once. Unknown ownership and 18 unresolved evidence outcomes can delay particular slices without forcing a guessed fix.
