# Phase 06 — Findings & Diagnostics

Complexity: **L**

## Goal

Provide dedicated, deterministic investigation views for findings and diagnostics.

## Behavior

- Search by file path, title, rule ID, and supported finding text.
- Filters by severity, category, confidence, application scope, and source availability.
- Deterministic ordering by supported severity/category/path/source position/stable ID.
- Diagnostic list with blocking status, exact message, range, and rationale.
- Evidence integrity details and navigation to source when available.

## Acceptance

No invented priority score is shown. Overlapping application attribution does not duplicate global counts. Diagnostics and evidence semantics remain exact.
