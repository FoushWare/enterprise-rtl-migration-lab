# Phase 04 — Arabic / English Localization

Complexity: **M**

## Goal

Support English and Arabic UI while preserving technical content and code readability.

## Behavior

- Static English and Arabic UI dictionaries.
- Locale switch in the shell.
- Arabic UI regions use RTL direction.
- Code, paths, rule IDs, IDs, source locations, and source text remain LTR and isolated.

## Acceptance

Arabic labels, mixed-direction finding titles, paths, and source content render without punctuation or location corruption. No scanner data is translated or rewritten.
