# Phase 05 — Overview & Analysis

Complexity: **M**

## Goal

Add a useful scan overview without turning the product into a metrics-only dashboard.

## Behavior

- Completeness and integrity status.
- Findings, actionable findings, affected files, and diagnostics summaries.
- Severity, category, rule, confidence, ownership, and application breakdowns.
- Skipped paths, missing/duplicate evidence, blocking diagnostics, and unresolved reachability warnings.
- Clear static-analysis disclaimer.

## Constraints

Use only schema-backed values. Do not add readiness percentages, trend claims, effort estimates, or automatic remediation status.
